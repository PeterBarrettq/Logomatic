 How to run the Java application
 ********************************
Ensure that your computer have Java-JRE installed on their system. 

If its already installed check by running java -version in their terminal or command prompt.

To run the .jar file, your client can use the following command:

java -jar myapp.jar

OR 

Directly click on .jar file.
